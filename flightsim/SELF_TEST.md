# 自测报告（对照验收标准逐条验证）

> 验证日期：随本项目一同发布。验证方式：无头物理测试（`npm run physics:test`，33 项断言）、
> TypeScript 严格编译、生产构建、Playwright 浏览器探针（UI 13 项、自动驾驶飞行序列）。
> 浏览器探针在 headless Chromium + SwiftShader 软件渲染下运行。

## 验收标准逐条对照

### 1. 能从跑道滑跑、抬轮并爬升，行为符合直觉 —— ✅ 通过

无头物理测试（`physicsTest.ts` 第 1 节）：
- 满油门滑跑 16 s：不拉杆不自行为离地，速度达 29.3 m/s（57 kt），滑跑距离 233 m；
- 抬轮（Vr 速度满杆至 5° 后减杆）：34.8 m/s（68 kt）离地，爬升率 4.0 m/s（787 fpm，与 C-172 相符）；
- 爬升中姿态受控。浏览器自动驾驶探针同样通过"滑跑加速至抬轮速度"与"抬轮离地"两项。

### 2. 失速可复现；大攻角拉杆速度下降时机头下坠；推杆可改出 —— ✅ 通过

无头物理测试（第 2 节）：
- 40 m/s 拉满杆：速度降至 14.6 m/s，α 超过临界攻角 13.4° 进入失速，失速告警触发，升力不足下沉；
- 松杆后俯仰角从 29.3° 回落至 −6.6°（机头下坠）；
- 推杆后 α 恢复至 −1.7°，速度恢复至 86 m/s，失速告警解除。
浏览器自动驾驶探针同样验证"失速复现（α 28°、速度下降、告警）"与"推杆改出（攻角恢复、姿态改平）"。

### 3. 能完成起飞、巡航、转向、进近、着陆的完整起降且不坠毁 —— ⚠️ 分段验证通过，自动化全流程仍有一项在调试

- 起飞 / 爬升 / 巡航稳定性：物理测试通过（第 1、5 节：30 s 平飞不发散、速度保持合理范围）；
- 转向与进近：自动驾驶探针"180° 转向返场"与"下降至进近高度"两项通过；
- 着陆判定：物理测试通过（第 3 节：进近拉平后接地下降率 0.55 m/s 软着陆不坠毁）；
- **未完成项（如实说明）**：浏览器自动驾驶探针的"着陆（拉平接地）"段仍在调试
  —— 探针在失速改出后位置偏移过大，返场下降衔接出现失控，属测试控制器问题，
  不影响手动飞行（手动着陆由第 3 节物理测试覆盖）。该探针为测试专用钩子，非游戏功能。

### 4. 第一人称仪表读数与 HUD 数值一致，随飞行实时变化 —— ✅ 通过

- 仪表与 HUD 均直接读取同一 `flightEngine.state`（单一数据源）；
- HUD 数值由 rAF 逐帧更新（IAS/ALT/V/S/HDG/THR/RPM），浏览器探针验证数值随飞行变化；
- 六块 Canvas 仪表（空速/高度/姿态/航向/升降率/转速）在座舱视角渲染非空白，指针指数平滑；
- 单位一致：空速 kt、高度 ft、升降率 ft/min，换算集中在 `utils/format.ts`。

### 5. 视角切换、暂停、重置、设置功能正常 —— ✅ 通过

Playwright UI 探针 13/13 通过：主菜单、操作说明键位表、设置面板（灵敏度滑杆）、
键位自定义列表、飞行画面（HUD+Canvas）、座舱视角仪表簇、暂停/继续、重置（IAS 归零、
位置回出生点）、返回主菜单、任务模式面板、控制台无 error、页面无未捕获异常。

### 6. 控制台无报错，TypeScript 编译通过，构建产物可运行 —— ✅ 通过

- `tsc --noEmit`（strict、noUnusedLocals 等）零错误；
- `npm run build`（vite build）成功，产物 gzip 约 285 KB；
- 浏览器全程控制台无 error、无页面异常（仅 headless SwiftShader 的 GL 性能提示，
  非应用错误，真实 GPU 环境不出现）。

### 7. 飞机不与地面穿模 —— ✅ 通过

- 三点式起落架弹簧-阻尼接触模型（刚度 42 kN/m、阻尼 3.6 kN·s/m），
  静载下支柱压缩量 ~8 cm，飞机稳定停在道面以上；
- 附加兜底保护（异常深陷时强制抬升）；起落架收起时接地立即判定坠毁（物理测试验证）。

### 8. 着陆过重判定坠毁并提示 —— ✅ 通过

- 接地下降率 > 3.5 m/s（约 690 fpm）判定"着陆过重"坠毁（物理测试：6 m/s 接地 → reason=hard-landing，
  提示含实际下降率 2855 ft/min）；软着陆（0.55 m/s）不触发；
- 坠毁后弹出"坠毁"覆盖层（原因 + 重新开始/返回主菜单），物理冻结。

## 补充自测

- **姿态耦合**：右舵产生侧滑（β=21°）且松舵后风标稳定收敛；右压杆产生右滚并伴随偏航变化
  （滚转-偏航耦合）——物理测试第 4 节通过；
- **边界处理**：飞出 4800 m 硬边界判定坠毁并提示（物理测试第 6 节通过）；
- **确定性**：相同输入 → 逐位相同的状态轨迹；仿真时间推进精确（第 7 节通过）；
- **配平**：0.13 rad 抬头配平松杆后维持 11.8° 姿态、4.6 m/s 爬升（第 8 节通过）；
- **性能**：桌面 GPU 目标 60 fps（几何合并、实例化云树、单 draw call 天空、HUD 无 React 重渲染）；
  headless 软件渲染下按设计降速运行（物理与渲染解耦的直接体现）。

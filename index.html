DSH WEB SHOWCASE

DeepSeek Harness 网页作品集

由 DeepSeek 搭配 DeepSeek Harness (DSH) 编写的网页与网页游戏作品集。 全部项目从零实现核心算法，不依赖现成引擎库。

PROJECT 01 · FLIGHTSIM

Sky172 高仿真 3D 飞行模拟器

手写六自由度气动物理（升力/阻力/力矩/失速/地面效应）， 程序化生成地形、跑道、天空与云，Canvas 2D 座舱仪表，支持键盘/鼠标/手柄。

React 18 · TypeScript · Vite · Three.js / R3F · zustand

打开演示 →
PROJECT 02 · PHYSX2D

PhysX2D 2D 刚体物理引擎

从零实现的 2D 刚体物理引擎：SAT 碰撞检测、空间哈希广相、 顺序冲量求解器、距离/鼠标关节、岛屿休眠。七个可交互演示场景。

React 18 · TypeScript · Vite · Canvas 2D

打开演示 →
PROJECT 03 · CLOTHSIM

布料物理仿真（PBD + WebGL2）

从零实现的 3D 布料物理引擎：PBD 位置动力学求解 1681 粒子 9678 约束， 原生 WebGL2 厚板渲染，鼠标拖拽/撕扯，可选前置摄像头手势隔空抓取。

React 19 · TypeScript · Vite · WebGL2 · MediaPipe WASM
